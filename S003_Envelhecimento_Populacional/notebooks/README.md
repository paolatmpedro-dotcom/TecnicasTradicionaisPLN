# Notebooks

## S003_Envelhecimento_Populacional_Estado_Nutricional.ipynb

Notebook executável do projeto, preparado para Jupyter.

O notebook executa `src/s003_envelhecimento_populacional_estado_nutricional_final.py`, que coleta artigos do PubMed, cria o corpus, aplica pré-processamento bilíngue, executa busca TF-IDF e baseline lexical, calcula métricas exploratórias e gera cinco gráficos, incluindo uma nuvem de palavras. Os rótulos são heurísticos, não anotações humanas independentes.
